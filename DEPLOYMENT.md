# 🚀 CryptLink Deployment Guide

## 📋 Prerequisites

### Required Services
- **PostgreSQL** (Database)
- **Redis** (Caching & Sessions)
- **Node.js 18+** (Frontend)
- **Java 17+** (Backend)
- **Cloud Storage** (Media files)

### Free Hosting Options
- **Frontend**: Vercel, Netlify, GitHub Pages
- **Backend**: Railway, Render, Heroku (free tier)
- **Database**: Supabase (PostgreSQL), ElephantSQL
- **Redis**: Redis Cloud (free tier), Upstash
- **Storage**: Cloudflare R2 (free tier), Supabase Storage

## 🔧 Environment Setup

### 1. Backend Configuration

Create `.env` file in `backend/` directory:

```bash
# Database (PostgreSQL)
SPRING_DATASOURCE_URL=jdbc:postgresql://your-db-host:5432/cryptlink
SPRING_DATASOURCE_USERNAME=cryptlink_user
SPRING_DATASOURCE_PASSWORD=secure_password_123

# Redis
SPRING_DATA_REDIS_HOST=your-redis-host
SPRING_DATA_REDIS_PORT=6379
SPRING_DATA_REDIS_PASSWORD=redis_password_123

# JWT (Generate a secure 256-bit key)
JWT_SECRET=your_super_secure_jwt_secret_key_minimum_256_bits_long
JWT_EXPIRATION=86400000
JWT_REFRESH_EXPIRATION=604800000

# CORS (Add your frontend domain)
ALLOWED_ORIGINS=https://yourdomain.vercel.app,https://yourdomain.com

# File Storage
CLOUD_STORAGE_PROVIDER=cloudflare_r2
CLOUD_STORAGE_BUCKET=cryptlink-media
CLOUD_STORAGE_ACCESS_KEY=your_r2_access_key
CLOUD_STORAGE_SECRET_KEY=your_r2_secret_key
```

### 2. Frontend Configuration

Create `.env` file in `frontend/` directory:

```bash
REACT_APP_API_URL=https://your-backend-url.railway.app/api
REACT_APP_WS_URL=wss://your-backend-url.railway.app/ws
REACT_APP_ENV=production
```

3. Get REST URL and token
4. Add to environment variables

1. Go to [redis.com](https://redis.com)

3. Get connection details

## 📦 Deployment Steps

### 1. Deploy Backend (Railway)

```bash
# Clone and build
git clone https://github.com/yourusername/cryptlink.git
cd cryptlink/backend

# Create railway.toml
cat > railway.toml << EOF
[build]
builder = "NIXPACKS"

[deploy]
healthcheckPath = "/api/health"
healthcheckTimeout = 100
restartPolicyType = "ON_FAILURE"
restartPolicyMaxRetries = 10

[[services]]
name = "cryptlink-api"

[services.variables]
SPRING_PROFILES_ACTIVE = "prod"
EOF

# Deploy to Railway
railway login
railway link
railway up
```

### 2. Deploy Frontend (Vercel)

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
cd frontend
vercel --prod

# Add environment variables in Vercel dashboard
```

### 3. Configure Cloud Storage (Cloudflare R2)

```bash
# Install wrangler CLI
npm install -g wrangler

# Create R2 bucket
wrangler r2 bucket create cryptlink-media

# Upload initial files (optional)
wrangler r2 object put cryptlink-media/default-avatar.png --file=./path/to/image.png
```

## 🔐 Security Configuration

### 1. JWT Secret Generation

Generate a secure 256-bit key:

```bash
# Using OpenSSL
openssl rand -base64 32

# Or using Node.js
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

### 2. Database Security

```sql
-- Create dedicated database user
CREATE USER cryptlink_user WITH PASSWORD 'secure_password';
GRANT ALL PRIVILEGES ON DATABASE cryptlink TO cryptlink_user;

-- Enable SSL (recommended for production)
ALTER DATABASE cryptlink SET ssl = on;
```

### 3. Environment Security

- Never commit `.env` files to Git
- Use different secrets for development and production
- Rotate secrets regularly
- Use environment-specific configurations

## 🔄 CI/CD Pipeline

### GitHub Actions Example

```yaml
# .github/workflows/deploy.yml
name: Deploy CryptLink

on:
  push:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'
      - name: Install dependencies
        run: |
          cd frontend && npm ci
          cd ../backend && ./mvnw install
      - name: Run tests
        run: |
          cd frontend && npm test
          cd ../backend && ./mvnw test

  deploy-backend:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Deploy to Railway
        uses: railway-app/railway-action@v1
        with:
          api-token: ${{ secrets.RAILWAY_TOKEN }}
          service: cryptlink-api

  deploy-frontend:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Deploy to Vercel
        uses: vercel/action@v1
        with:
          vercel-token: ${{ secrets.VERCEL_TOKEN }}
          vercel-org-id: ${{ secrets.ORG_ID }}
          vercel-project-id: ${{ secrets.PROJECT_ID }}
```

## 🔍 Troubleshooting

### Common Issues

1. **CORS Errors**
   ```bash
   # Check allowed origins
   echo $ALLOWED_ORIGINS
   ```

2. **Database Connection**
   ```bash
   # Test connection
   psql $DATABASE_URL
   ```

3. **Redis Connection**
   ```bash
   # Test Redis
   redis-cli -u $REDIS_URL ping
   ```

4. **JWT Issues**
   ```bash
   # Verify JWT secret length (should be 256+ bits)
   echo -n "$JWT_SECRET" | wc -c
   ```

### Health Check Endpoint

```java
@RestController
public class HealthController {
    @GetMapping("/api/health")
    public ResponseEntity<Map<String, String>> health() {
        return ResponseEntity.ok(Map.of(
            "status", "UP",
            "timestamp", Instant.now().toString()
        ));
    }
}
```
